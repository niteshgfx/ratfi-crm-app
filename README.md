# RatFi CRM – Android app

**Download:** [RatFi-CRM.apk](https://github.com/niteshgfx/ratfi-crm-app/raw/main/RatFi-CRM.apk)

1. Open the link above on your Android phone.
2. Open the downloaded file and tap **Install** (allow "Install unknown apps" for your browser if asked).
3. Sign in with your RatFi CRM account. New company? Tap **Register your company**.

Website: https://crm.ratfi.in · Privacy & legal: https://crm.ratfi.in/legal.html · Support: support@ratfi.in

This repository only holds the app download; the source code is private.
